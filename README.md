# 📱 GiphySearchApp

A modern Android application built with **Kotlin** and **Jetpack Compose** that allows users to search, view, and favorite GIFs using the **GIPHY API**. The app follows clean architecture principles, provides smooth UI interactions, and offers friendly favorites storage.

---

## 🚀 Features

### 🔍 Search GIFs
- Real-time GIF search powered by the GIPHY API  
- Pagination support  
- Clean UI with adaptive layouts  

### ⭐ Favorites
- Mark/unmark any GIF as a favorite  
- Favorites stored  
- Dedicated Favorites Screen with navigation  

### 🖼️ GIF Details
- Full-screen GIF preview  
- Share GIFs with other apps  
- Smooth transitions & Compose animations  

### 📦 Modern Architecture
- 100% **Jetpack Compose UI**  
- **MVVM** + **Repository** pattern  
- **Kotlin Serialization** for network models  
- **Retrofit** + **OkHttp** for API  
- **Coroutines + Flow** for async & state  
- Clean and maintainable package structure  

---

## 🛠️ Tech Stack

| Layer | Technologies |
|------|--------------|
| **UI** | Jetpack Compose, Material 3 |
| **Language** | Kotlin |
| **Architecture** | MVVM, Repository |
| **Networking** | Retrofit, OkHttp, Kotlin Serialization |
| **State** | ViewModel + Flow |
| **Persistence** | DataStore |
| **Image Loading** | Coil for GIF loading |
